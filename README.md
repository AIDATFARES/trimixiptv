# Trimix IPTV - Premium 4K IPTV Service & Global Streaming Platform

Official website repository for **Trimix IPTV** (`www.trimixiptv4k.online`).

## Features
- **50,000+ Live Channels**: Global TV channels covering sports, news, movies, and entertainment.
- **120,000+ Movies & Series**: Full VOD library with multi-language support.
- **4K Ultra HD & Anti-Freeze**: Multi-CDN streaming infrastructure for 99.9% uptime.
- **Cross-Platform Compatibility**: Supports Smart TVs, Firestick, Android, iOS, Windows, Mac, and MAG boxes.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4 with custom Cyber Violet/Cyan theme
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Build & Production

To build the static / optimized production assets:

```bash
npm run build
```
